# WHENMUSIC — 요구사항

> 프로젝트 정의는 [01_프로젝트.md](01_프로젝트.md), 기술 결정은 [03_기술_스펙.md](03_기술_스펙.md). ID 체계와 문서 형식은 WHENCALENDAR `docs/02_요구사항.md`를 따른다. 2026-09-18 정의. 체크는 자동 테스트가 증명한 것만 — UI 항목은 실사용으로 확인한 뒤 체크한다. **POC로 가능성만 확인된 것은 체크하지 않고 본문에 실측 사실을 적는다.**

**Core Value:** 음악을 만지려고 창을 찾지 않는다. 좋은 곡이 지나갔을 때 그 자리에서 되감는다.

## v1 Requirements

### 카드 오버레이 (CARD)

이 앱의 존재 이유다. 나머지 그룹은 전부 이걸 받쳐 준다.

- [ ] **CARD-01**: 화면 **우하단**에 카드가 상주한다. 프레임 없는 투명 창이고, 앱을 실행한 뒤 아무 설정 없이 바로 뜬다. 작업표시줄을 피해 `workArea` 기준으로 배치한다
- [ ] **CARD-02**: 카드는 **전체화면 앱 위에** 뜬다. 전체화면 IDE·브라우저 영상에서 가려지지 않는다. z-order를 1초 주기로 다시 잡는다 ([D-08](03_기술_스펙.md#d-08-카드는-우하단에-고정한다))
- [ ] **CARD-03**: 카드는 **마우스 클릭을 통과시킨다.** 카드 아래에 있는 창을 그대로 누를 수 있다. 단 카드 위의 버튼은 눌린다
- [ ] **CARD-04**: 카드는 **포커스를 뺏지 않는다.** 뜨거나 바뀔 때 타이핑하던 창의 커서가 유지된다
- [x] **CARD-05**: 카드는 곡이 아니라 **지금 재생 중인 것**을 보여 준다 — 제목, 채널·아티스트, 소스 앱, 현재 위치와 전체 길이, 진행바
- [ ] **CARD-06**: 배경에 썸네일을 **블러 6px**로 깔고, **전면 덮개 대신 좌측에서 우측으로 빠지는 띠**와 `text-shadow`로 글자를 보호한다. 썸네일이 어떤 비율·밝기로 와도 레이아웃이 흔들리지 않고, 썸네일이 없어도 같은 모습이다 ([D-09](03_기술_스펙.md#d-09-블러는-6px-덮개-대신-좌측-띠로-글자를-지킨다))
- [ ] **CARD-07**: 진행바에 **도장 눈금**이 보인다. 방금 찍은 것은 밝게, 이전 것은 흐리게
- [ ] **CARD-08**: 카드에 **마우스를 올리면** 이번 세션의 도장 목록으로 바뀐다. 마우스를 빼면 돌아온다
- [x] **CARD-09**: 제목에 섞인 유니코드 수학 문자·전각 기호를 **NFKC로 정규화**해 표시한다 (`𝐏𝐥𝐚𝐲𝐥𝐢𝐬𝐭` → `Playlist`). 원문도 함께 저장한다
- [ ] **CARD-10**: 재생 중이 아니면 카드가 상태를 구분해 보여 준다 — **일시정지**(색이 빠지고 흐려짐) · **세션 없음**(안내를 8초 보여준 뒤 사라짐) · **연결 실패**(원인과 필요 조건을 한 줄로)
- [ ] **CARD-11**: 세션이 둘 이상이면 **어느 것을 제어 중인지** 카드에 드러나고, 다른 세션으로 바꿀 수 있다
- [ ] **CARD-12**: 길이를 모르는 라디오 스트림은 진행바를 **0%로 두지 않고 숨긴다.** 멈춰 있는 바는 고장으로 읽힌다
- [ ] **CARD-13**: 설정에서 카드 위치(우하단·좌하단), 블러 세기, 되감기 폭을 바꾼다

### 제어 (CTL)

- [x] **CTL-01**: 카드에서 **재생·일시정지**를 한다. 브라우저 탭이나 플레이어 창을 찾아가지 않는다
- [ ] **CTL-02**: 카드에서 **이전·다음**으로 넘긴다
- [x] **CTL-03**: **10초 되감기.** 카드 버튼과 `Ctrl+Alt+←`로 한다. 되감은 직후 잠깐 되감은 양을 글자로 말한다 — 2026-09-18 POC에서 `TryChangePlaybackPositionAsync`가 브라우저 세션에 **오차 0으로 착지**함을 확인
- [x] **CTL-04**: 제어는 **앱 id로 세션을 지목해** 보낸다. 유튜브 탭 대신 화상회의 탭이 멈추는 일이 없다 — 키보드 미디어 키로는 불가능한 동작이고, POC에서 Chrome 세션만 지목해 `TryPauseAsync`가 적용됨을 확인
- [x] **CTL-05**: 진행바를 눌러 **그 지점으로 이동**한다. 도장 눈금을 누르면 그 도장 위치로 간다
- [ ] **CTL-06**: 버튼을 누르면 **UI가 먼저 바뀌고** 실제 상태가 오면 맞춘다. 명령 수락(약 5ms)보다 SMTC 상태 반영이 늦기 때문이다 ([D-14](03_기술_스펙.md#d-14-ui는-낙관적으로-먼저-바꾼다))
- [ ] **CTL-07**: 제어가 불가능한 세션(`IsPauseEnabled` 등이 거짓)에서는 해당 버튼을 **누를 수 없게 보여 준다.** 눌리는데 아무 일도 안 일어나면 고장으로 읽힌다

### 되감기·도장 (STMP)

"좋은 곡을 놓친다"를 푸는 그룹이다. **주 동작은 되감기(CTL-03)이고, 도장은 되감을 여유조차 없을 때의 보조다.**

- [x] **STMP-01**: `Ctrl+Alt+S` 또는 카드 버튼으로 **지금 위치에 도장을 찍는다.** 확인을 요구하지 않는다
- [ ] **STMP-02**: 찍은 직후 **1.4초 동안만** 표시하고 평소 카드로 돌아간다. 소리는 내지 않는다
- [x] **STMP-03**: 도장은 `{ 소스 앱, 제목, 채널, 위치(초), 찍은 시각, 확인 여부 }`를 남긴다
- [ ] **STMP-04**: 도장을 눌러 **그 지점으로 되돌아간다.** 같은 세션이 살아 있으면 시크로, 아니면 소스 URL로 연다 ([오픈이슈 #1](03_기술_스펙.md#오픈이슈))
- [x] **STMP-05**: 되돌아가 들은 도장은 **확인 처리**된다. 확인 안 한 도장의 개수가 창 탭에 배지로 붙는다
- [ ] **STMP-06**: 같은 세션에 찍은 도장이 진행바에 전부 눈금으로 남는다

### 이력 창 (HIST)

- [ ] **HIST-01**: `Ctrl+Alt+P`로 창을 열고 닫는다. 창 위치·크기를 기억한다 (WHENWORK `place.mjs` 승계)
- [ ] **HIST-02**: 탭은 **이력 · 도장 · 설정**이고 `Tab`으로 돈다. **이력이 첫 탭**이고, 도장 탭에는 확인 안 한 개수가 배지로 붙는다 ([D-12](03_기술_스펙.md#d-12-이력은-믹스-단위-도장은-별도-탭))
- [ ] **HIST-03**: **이력** 탭은 한 줄이 **한 번 들은 믹스**다. 시작 시각·썸네일·제목·채널·소요 시간·도장 개수를 보여 주고 날짜로 묶는다. 곡 단위가 아니다
- [x] **HIST-04**: 같은 영상을 이어 들으면 **한 줄로 합친다.** 30분 넘게 끊기면 새 줄로 나눈다
- [ ] **HIST-05**: `Enter`로 그 믹스를 **마지막에 들은 지점부터 이어 재생**한다
- [ ] **HIST-06**: **도장** 탭은 한 줄이 **표시해 둔 한 순간**이다. 확인 안 함 / 전체 / 이 채널로 거르고, `Enter`로 그 지점부터, `X`로 확인 처리한다
- [ ] **HIST-07**: 날짜별·주별 청취 시간 합계가 보인다. 길이를 모르는 스트림은 실제 소요 시간으로 센다
- [ ] **HIST-08**: 마우스 없이 전부 조작된다. `?`로 전체 키맵을 본다. 키 글자의 뜻은 형제 앱과 같다(`X` 삭제, `U` 되돌리기, `/` 검색)
- [ ] **HIST-09**: 창을 닫아도 앱은 트레이에 남고 카드는 계속 동작한다
- [ ] **HIST-10**: 기본 창 크기는 720×520, 최소 620×440이다

### 검색 (SRCH)

- [ ] **SRCH-01**: `/`로 검색한다. 검색창이 곧 입력창이다 (WHENNOTE 규칙)
- [x] **SRCH-02**: 부분 문자열과 **한글 초성**으로 찾는다 (`ㅎㅎ` → 힙합). `whennote/main/search.mjs`의 순수 모듈을 이식한다
- [x] **SRCH-03**: 검색은 **정규화된 제목**을 대상으로 한다. 유니코드 볼드로 쓰인 제목이 검색에서 빠지지 않는다
- [x] **SRCH-04**: 채널명으로도 찾고, 소스 앱으로 거른다

### 저장소 (STOR)

- [x] **STOR-01**: 데이터는 `%APPDATA%\whenmusic`의 `store.sqlite` 하나에 있다. 계정도, 외부 데이터베이스도 없다
- [x] **STOR-02**: 재생 이력은 **앱이 관측한 것만** 쌓인다. 앱이 꺼져 있던 시간은 비어 있고, 그 사실이 이력에서 드러난다
- [x] **STOR-03**: 썸네일은 세션마다 **한 번만** 저장한다(약 23KB). 같은 영상을 다시 들으면 재사용한다
- [x] **STOR-04**: 삭제는 소프트 삭제이고 `U`로 되돌린다. 30일이 지난 것만 실제로 지워진다 (형제 앱 삭제 규칙 승계)

### 내보내기·가져오기 (DATA)

- [x] **DATA-01**: 전부 JSON 하나로 내보낸다. 이력·도장·설정이 들어간다
- [x] **DATA-02**: 가져오기는 지금 데이터를 **갈아끼우고**, 직전 상태를 `before-import-<시각>.json`으로 남긴다
- [ ] **DATA-03**: 설정 화면이 데이터 폴더 경로를 보여 주고 열어 준다

### 첫 실행·플랫폼 (PLAT)

- [ ] **PLAT-01**: 설치 파일 하나를 실행하면 끝이다. 다른 프로그램·런타임을 요구하지 않는다
- [ ] **PLAT-02**: Windows 10 1809(10.0.17763) 이상에서 동작한다. 그 미만에서는 **SMTC를 쓸 수 없다는 사실과 필요 버전을 카드에 적는다** (CARD-10)
- [x] **PLAT-03**: 네이티브 애드온 로드에 실패해도 **앱이 죽지 않는다.** 이력 창은 열리고 이미 쌓인 기록을 읽을 수 있다
- [ ] **PLAT-04**: 자동 시작을 설정에서 켜고 끈다
- [x] **PLAT-05**: 앱 이름·데이터 폴더·단일 인스턴스 락이 형제 앱과 전부 달라 다섯 앱이 한 PC에서 동시에 돈다
- [ ] **PLAT-06**: OS에 기대는 코드는 `main/platform/` 안에만 둔다. macOS 분기(v2)가 이 경계로만 들어온다

### 릴리스 (REL)

- [x] **REL-01**: `electron-builder`로 Windows NSIS 설치 파일을 만든다. 미서명이고, 첫 실행 경고를 README가 안내한다
- [ ] **REL-02**: GitHub Releases로 배포하고 `electron-updater`가 갱신을 알린다. 켜고 1분 뒤 한 번, 이후 하루 한 번 확인한다
- [ ] **REL-03**: 새 버전은 **앱을 종료할 때** 설치한다. 쓰는 도중에 스스로 재시작하지 않는다
- [x] **REL-04**: 네이티브 애드온은 **GitHub Actions에서 빌드**한다. 개발 PC에 Rust·MSVC를 설치하지 않는다 ([D-06](03_기술_스펙.md#d-06-애드온은-ci에서만-빌드한다))
- [x] **REL-05**: 애드온 포크는 원저작자 표시와 MIT 라이선스 문구를 유지한다 (`Copyright (c) 2025 LeagueTavern`)

### 완료 판정 (DONE)

- [ ] **DONE-01**: 작성자가 2주 사용한 뒤 **"음악을 조작하려고 브라우저 탭을 찾아간 횟수"가 0에 가깝고, "좋은 곡이 지나갔는데 그냥 넘긴 날"이 0일**

## v2 Requirements

- **회의 자동 일시정지** — 마이크 점유(`HKCU\...\CapabilityAccessManager\ConsentStore\microphone`의 `LastUsedTimeStop == 0`)로 감지해 멈추고, 끝나면 되돌린다. 기술 검증은 끝났고 주 사용자의 불편이 아니라 v1에서 뺐다
- **macOS** — `MPNowPlayingInfoCenter`로 다시 쓴다. SMTC는 Windows 전용이다
- **소스 URL 확보** — videoId를 얻어 도장을 며칠 뒤에도 되살린다 ([오픈이슈 #1](03_기술_스펙.md#오픈이슈))
- **되감기 폭 학습** — 실제로 되감은 뒤 다시 조정한 양을 보고 기본값을 옮긴다
- **청취 통계** — 채널별·시간대별 집계
- **다중 모니터 위치 선택**

## Out of Scope

| 기능 | 이유 |
|---|---|
| 곡 이름 식별 (챕터 파싱·핑거프린팅) | [01 §스코프](01_프로젝트.md#제외). 되감기가 이 필요를 대신한다 |
| 자체 재생 (로컬 파일·스트림) | 재생 장치를 갖는 순간 층이 아니라 앱이 된다 |
| Spotify·YouTube Music OAuth | Premium 전제 + 심사·검증 비용. WHENCALENDAR 선례 승계 |
| 라이브러리 관리·태그 편집·EQ·DSP | MusicBee·AIMP·foobar2000의 일 |
| 가사·추천·발견·생성 사운드스케이프 | 몰입 청취의 정답은 반복이고 발견은 그 반대다 |
| 클라우드 동기화·계정·협업 | 1인 1PC. 형제 앱 동일 |

|---|---|---|
